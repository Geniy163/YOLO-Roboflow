## 🚀 Быстрый старт

1. Нажмите на бейдж **Open in Colab** выше, чтобы открыть блокнот обучения.
2. Подключите **T4 GPU** в среде выполнения (`Runtime -> Change runtime type`).
3. Вставьте ваш код интеграции с **Roboflow** и запустите выполнение ячеек.
4. Скачайте сгенерированные файлы: `my_model.pt` (для ПК).
